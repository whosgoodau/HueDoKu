# HueDoKu

A sudoku where every digit is also a colour. Single file, no libraries: open `index.html` in a browser.

This repo holds only the latest version: **v4** (`index.html` is `HueDoKuGX_v4.html`).

- Numbers on/off and colours on/off (keys **N** and **C**; at least one stays on)
- Restart the same puzzle
- Short puzzle IDs (like `M1KLBRGO`) that rebuild the same puzzle on any device: type one into Enter / share, or copy the ID of the puzzle you are playing
- Players, puzzle IDs, archive and saved games (in your browser)
- Logo: `logo/HueDoKuLogo_A_Glass.svg`
